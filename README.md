# Velo TV

Velo TV is a Twitch viewer for Apple TV, built with SwiftUI.

It is designed around the Siri Remote with fast browsing, clear focus states, live stream playback, optional Twitch login, followed channels, chat, and third-party emote support.

## Features

- Browse live Twitch streams on tvOS
- Search channels, stream titles, and games
- Optional Twitch device-code login
- Followed live channels on the home screen
- Chat with Twitch badges and 7TV, BetterTTV, and FrankerFaceZ emotes
- Video-synced chat mode
- App Store-ready tvOS assets and privacy manifest

## Build

Open `Velo.xcodeproj` in Xcode, select the `Velo` tvOS scheme, then build and run on an Apple TV simulator or device.

## Notes

Velo TV is an independent project and is not affiliated with Twitch.
